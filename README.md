# Classifier Lab

An interactive, in-browser tool for IL3064 (AI & Machine Learning) — NLP Module 6:
*Building Your Own Text Classifier*.

Students train real Naive Bayes, Logistic Regression, and Linear SVM classifiers
entirely client-side (no server, no libraries — the math is implemented from
scratch in JavaScript and shown at every step: what the model is doing, why,
and how, including the literal word-by-word contribution scores behind each
prediction).

Three ways to use it:

1. **Toy dataset** — the same 20-sentence starter set from the lecture, showing
   why small data makes classifiers unstable.
2. **Hotel reviews dataset** — 109 real TripAdvisor reviews, showing how
   accuracy improves with more data.
3. **Bring your own dataset** — paste your own positive/negative examples and
   train on them directly, as a hands-on follow-up assignment.

**Live tool:** see the Pages link in the repo's About section.

Built for Prof. Saranraj's AI & ML course, Odd Semester 2026–27.
